# Security reporting

This repository hosts Rentala's privacy-policy website; it does not contain the Android application's source code.

If you find a security issue in this website or believe the published policy exposes sensitive information, email [ctucay.terre@gmail.com](mailto:ctucay.terre@gmail.com) with a concise description and reproduction steps. Please do not post sensitive details publicly before the maintainer has had a reasonable opportunity to review them. Never send tenant records, account credentials, access tokens, signing keys, or backup files in a report.

Security reports for the Rentala Android application may use the same contact address. This repository does not promise a particular response time or bug-bounty payment.
